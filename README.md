# DX11 Chalkboard

코드에는 파일별 역할과 주요 처리 흐름을 설명하는 한국어 주석을 추가했습니다. 저장·불러오기 형식, 압축, 검사, 레이어 합성의 자세한 설명은 [저장·불러오기 구현 문서](Docs/SaveLoad.md)를 참고하세요.

기존 v0.15 Collision / GPU Picking 프레임워크에서 필요한 기반만 가져온 독립적인 3D 칠판 프로젝트입니다.

원본: `msg1150/Advanced_Game_Programming_Techniques`의 로컬 커밋 `b7c775b630bb57df0e7aceb8fef333b1f100f885` (2026-10-12, Add Collision, GPU Picking).
원본 GitHub 작업 폴더에는 파일을 생성하거나 수정하지 않았습니다. 원격 최신 커밋과의 대조는 네트워크 연결 문제로 수행하지 못했습니다.

## 실행 / 빌드

- 바로 실행: `bin/x64/Release/Chalkboard.exe`
- Visual Studio: `Chalkboard.sln` → x64 / Debug 또는 Release → 빌드·실행.
- PowerShell: `./build.ps1` (Release 기본값), `./build.ps1 -Configuration Debug`.
- 요구 환경: Windows 10/11, DirectX 11, Visual Studio C++ v143 도구 및 Windows SDK.
- 실행 파일 옆의 `Shaders` 폴더가 필요합니다. 빌드 시 자동으로 복사합니다.

## 조작

| 입력 | 동작 |
|---|---|
| 좌클릭 드래그 | 분필로 그리기 / 지우개로 지우기 |
| 우클릭 드래그 | 카메라 회전 |
| 마우스 휠 | 카메라 확대·축소. 도구 패널 위에서는 패널 스크롤 |
| Home | 카메라 정면 복원 |
| Ctrl+S | 작업 저장 |
| Ctrl+O | 작업 전체 열기 |
| Ctrl+Shift+O | 기존 그림 위에 추가 불러오기 |
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |

도구 패널의 슬라이더 또는 숫자 입력란으로 RGB(0~255), 분필 굵기(1~80), 지우개 크기(1~160)를 조절합니다.
굵기와 크기는 화면 픽셀이 아니라 칠판 캔버스 픽셀 기준이므로 카메라를 확대해도 실제 자국 크기가 바뀌지 않습니다.
숫자는 Enter로 적용하고 Esc로 취소합니다. 패널 아래쪽 버튼은 휠 또는 스크롤바로 접근할 수 있습니다.
색상 미리보기, 지우개 전환, 저장, 열기, 추가 불러오기, 투명 PNG 내보내기, 실행 취소, 다시 실행, 모두 지우기, 카메라 복원, Collider 표시를 제공합니다.

## 필기 규칙

- 초록색 판의 앞면만 그릴 수 있습니다. 테두리·받침·옆면·뒷면에는 그리지 않습니다.
- 마우스 이벤트를 프레임의 마지막 위치 하나로 축약하지 않고 순서대로 처리합니다. 한 프레임 안의 짧은 클릭도 보존합니다.
- 연속 좌표 사이를 선분과 원형 끝으로 채워 빠르게 움직여도 끊기지 않습니다.
- 누른 채 판 밖으로 나가면 경계에서 잘립니다. 돌아오면 새 클릭 없이 즉시 그립니다. 판 밖으로 나가기 전 점과 재진입 점을 대각선으로 잇지 않습니다.
- UI에서 시작한 드래그는 버튼을 놓을 때까지 UI가 소유합니다. 칠판으로 이동해도 그림이 생기지 않습니다.
- 필기 중 UI 위로 이동하면 그리기를 멈추고, 칠판에 돌아오면 이전 구간과 연결하지 않고 재개합니다.
- 필기 드래그 중에는 카메라 회전·휠 확대/축소·Home 복원을 차단합니다. 판 밖에서도 좌클릭을 놓기 전까지 유지합니다.
- 포커스 상실, 캡처 상실, 창 크기 변경 시 드래그를 종료합니다. 창 밖에서 버튼을 놓아도 캡처를 통해 종료합니다.

## 저장과 레이어

캔버스는 고정 1536×720 RGBA 픽셀입니다. 초록색 칠판 바탕과 그림 데이터는 별개입니다.

- `.chalk` 저장: 그림의 레이어별 RGBA 픽셀과 레이어 순서만 보존합니다. RLE 압축과 레이어별 체크섬을 사용하며 분필 RGB·굵기·지우개 크기는 저장하지 않습니다.
- 열기: 기존 그림을 저장본으로 교체하되 현재 도구 설정은 유지합니다. 저장하지 않은 변경이 있으면 폐기 여부를 확인합니다.
- 새 저장 파일은 버전 2(24바이트 헤더)입니다. 기존 버전 1 파일도 열 수 있으며, 그 안의 도구 설정은 무시하고 그림만 가져옵니다. 이전 실행 파일에서는 버전 2 파일을 열 수 없습니다.
- 추가 불러오기: 저장본의 그림 레이어를 현재 그림 위에 추가합니다. 마지막에 추가한 그림이 가장 위에 표시되고, 투명한 빈 영역은 아래 그림이 보입니다. 새 필기는 그보다 위의 빈 작업 레이어에 그립니다.
- 지우기: 해당 영역의 **모든 레이어**에서 RGB와 Alpha를 전부 0으로 초기화합니다. 아래 그림이 다시 드러나는 대신 원래 초록색 판이 보입니다. 저장본에도 비워진 픽셀을 기록합니다.
- 투명 PNG: 그림만 합성하여 내보냅니다. 초록색 바탕·나무 테두리·UI는 포함하지 않습니다. PNG는 편집용 레이어를 보존하지 않으며, 현재 불러오기는 `.chalk`만 지원합니다.
- 기본 저장 위치: 소스 프로젝트의 `Saves` 폴더. 실행 파일만 별도로 배포한 경우 실행 파일 옆 `Saves` 폴더.
- 파일 선택 창에서 다른 경로를 지정할 수 있습니다. 저장과 PNG 내보내기는 임시 파일을 완성한 뒤 교체합니다.
- 잘못된 형식, 손상된 체크섬, 다른 해상도, 잘린 파일, 과도한 레이어 수는 현재 작업을 바꾸지 않고 거부합니다.
- 레이어 상한은 빈 작업 레이어를 포함해 24개입니다. 상한을 넘는 추가 불러오기는 안내 후 취소합니다.
- 실행 취소는 한 번의 좌클릭 드래그를 하나로 취급합니다. 최대 8단계, 픽셀 스냅샷 약 128 MiB 범위에서 보관하므로 레이어 수가 많으면 보관 단계가 줄어듭니다. 실행 취소 데이터는 파일에 저장하지 않습니다.
- 모두 지우기도 실행 취소할 수 있습니다. 닫을 때 저장되지 않은 변경이 있으면 확인합니다. 자동 저장은 하지 않습니다.

## 가져온 기반과 새 기능

가져온 부분: `Platform/Window`, `Graphics/Renderer·Camera·Shader·Mesh·ConstantBuffer`, 기존 Direct2D/DirectWrite `UI`, Collision Core / Broad Phase / Narrow Phase / Raycast, `CollisionGeometry`, `GPUPickingSystem`.
Terrain, Terrain Streaming, Terrain UI, Terrain 텍스처·타일, UI Designer는 포함하지 않았습니다.

새 칠판 기능은 `Source/Features/Chalkboard`에 모았습니다.

- `BoardCanvas`: 레이어 픽셀, 선분 보간·경계 자르기, RGBA 지우기, 합성, 실행 취소, `.chalk` 저장·읽기.
- `StrokeTracker`: 드래그 유지, 판 재진입, UI 통과 시 연결 분리.
- `BoardScene`: 칠판 3D Mesh, OBB Collider, 마우스 Ray/앞면 교점과 UV 변환, GPU 텍스처, UI 바인딩, 파일 선택 창.
- `ImageFile`: 투명 PNG 저장, WIC 색상 형식 변환, 완료 후 파일 교체.
- `Application / Input`: 입력 이벤트 순서 보존, UI 우선 라우팅, 우클릭 카메라, 필기 중 카메라 차단.

GPU Picking은 좌클릭 시 칠판 Collider ID 선택에 사용합니다. 지연 없는 연속 필기는 CPU Ray와 앞면 교점으로 처리합니다.
Picking 전용 Depth를 사용하여 겹친 Collider에서도 가까운 Proxy가 선택되도록 했습니다. 칠판과 받침에는 OBB Collider가 있지만 캐릭터·중력·충돌 후 밀어내기 등 Physics Solver는 포함하지 않습니다.

## 검증

`./test.ps1`로 테스트 프로젝트를 빌드하고 실행합니다. DirectX WARP 소프트웨어 장치를 사용하므로 화면을 자동 조작하지 않고도 실제 HLSL과 DX11 출력까지 검사합니다.

검증 범위: 빠른 선 연결, 판 경계 이탈·재진입, UI 드래그 소유권, 포커스 상실, 모든 레이어 RGBA 지우기, 실행 취소·다시 실행, 레이어 순서, 파일 복원·손상 거부·상한, 앞면/뒷면 UV 판정, GPU 필기와 지우기 결과, 가장 가까운 GPU Picking, 투명 PNG의 RGB/Alpha 복원.

실제 칠판과 동일한 UI 백엔드로 만든 미리보기: `Tests/Artifacts/Preview.png`. 미리보기의 선은 검증용 샘플이며 앱 시작 시에는 빈 칠판입니다.
실제 창 자동 조작은 Computer Use 앱 접근 승인이 없어 수행하지 못했습니다. 네이티브 파일 선택 창, 실제 마우스 감각, 창 이동·리사이즈는 사용자 환경에서 추가 확인이 필요합니다.
